# 🧠 记忆口袋

> 拍照或截图 → AI 自动分类整理 → 随时随地搜索找回

## 功能

| 功能 | 说明 |
|------|------|
| 📦 取件码识别 | 自动识别快递取件码截图，提取取件码和快递点 |
| 💰 消费记录 | 识别支付截图，提取金额和商户信息 |
| 💡 灵感笔记 | 识别文字截图，自动归类为灵感笔记 |
| 💬 聊天截图 | 识别聊天对话，提取内容和平台 |
| 🏔️ 出游照片 | 识别出游照片，提取地点和场景描述 |
| 🔍 智能搜索 | 支持关键词和自然语言模糊搜索 |

## 技术栈

- **AI 引擎**: DeepSeek 多模态 API（图片识别 + 信息提取 + 搜索意图理解）
- **前端**: Gradio（Python Web UI）
- **存储**: SQLite 本地数据库
- **Vibe Coding 工具**: Claude Code + Context7 MCP + GitHub MCP + 10 个自定义 Skill

## 快速启动

### 方式一：桌面快捷方式
双击桌面的 `🧠启动记忆口袋.bat`

### 方式二：命令行
```bash
cd 桌面/记忆口袋
python app.py
```

启动后浏览器会自动打开 http://127.0.0.1:7860

## 项目结构

```
记忆口袋/
├── app.py            # 主程序 + Gradio UI
├── analyzer.py       # AI 分析引擎（DeepSeek API）
├── storage.py        # SQLite 数据存储
├── search.py         # 智能搜索
├── requirements.txt  # Python 依赖
├── .env              # API 密钥配置
├── images/           # 上传的图片存储
└── 启动记忆口袋.bat  # 一键启动
```

## 使用示例

1. 打开 App → 切换到"📸 录入记忆"
2. 上传一张快递取件码截图 → 点击"开始分析"
3. AI 自动识别为"取件码"，提取取件码号码和快递点
4. 切换到"📋 浏览记忆"查看所有记录
5. 在"🔍 智能搜索"中输入"取件码" 或 "上次那个快递" 进行搜索
6. 切换到"⏰ 待办事项"查看所有未处理的取件码
